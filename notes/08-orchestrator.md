# Шаг 8 — прораб

Платная модель больше не читает `users.json` глазами. Она вызывает `route`, исполнитель — скрипт.

| Роль | На этой задаче |
|------|----------------|
| Маршрутизатор | да, один раз |
| Автор кристалла | нет, скрипт уже есть |
| Ремонтник | нет, пока exit стабильный |
| Голова / wiring | только если route не узнал русскую фразу |

`crystallize promote` без `draft` падает. Имя в команде = `id` роута в yaml.
