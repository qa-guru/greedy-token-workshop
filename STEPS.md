# Восемь шагов

Одна задача: в `lab/users.json` у каждого объекта есть `id` и `email`.

Промпт копировать из [PROMPTS.md](PROMPTS.md). Новый чат на каждый шаг. В конце шага — коммит на ветке `prN-…` и PR.

Не вставлять в студенческий чат промпты «подготовки» (пакет, хаб-патч, переписать слайды). Это работа преподавателя до эфира.

| Шаг | Вопрос | Команда / инструмент | Готово, когда |
|-----|--------|----------------------|---------------|
| 1 | У меня вообще работает? | `pip install "greedy-token[mcp]"` · `doctor` · MCP или CLI | health ок, смоук «найди email» (это список адресов — так и надо на шаге 1) |
| 2 | Что скажет голый чат? | Тот же текст **пять раз**, **без** greedy-token | Либо разные ответы, либо запись: Agent с Read нашёл дырку стабильно — дрейф на Cursor не воспроизвёлся |
| 3 | Это поиск или схема? | `greedy_token_route` / jq, **не** искать слово `email` | Видны ключи объектов; у `id: 2` нет `email` |
| 4 | Проверка повторяется | `python3 lab/check_users.py …` | exit 1 / 0 / 2, JSON на stdout |
| 5 | Как у нас принято? | `greedy_token_rag` | Первый запрос → `users-keys`. «У каждого человека есть почта» → пусто или чужой чанк |
| 6 | Классифицировать пачкой | `greedy-token llm invoke --profile classify` | 7b, локально, без 30b |
| 7 | Ноут не тянет 30b | probe [ollama.qa.guru](https://ollama.qa.guru) `/api/tags` | 401 → стоп. 200 → heavy. Не подменять облако `localhost:11434` |
| 8 | Кто теперь платная модель? | один `greedy_token_route` | тир python / `python-check-users-keys`, вердикт из скрипта |
