# Задание на пару и дома

Стек: Python 3 · VS Code + Cline + Ollama. Cursor — по желанию.

## На паре

Пройти шаги 1 и 4 из [STEPS.md](STEPS.md). Скрипт `lab/check_users.py` уже в репо — его **гоняют**, на паре не переписывают с нуля, если зал отстаёт.

Шаги 5–6 по времени. 7–8 отрезаемые.

## Дома — один свой скрипт

Выбрать **одну** папку в `lab/homework/`:

| Папка | Правило | Дырка |
|-------|---------|-------|
| `allure-mini/` | у каждого result.json в `labels` есть `{ "name": "severity", ... }` | `bad-result.json` |
| `openapi-mini/` | в новом OpenAPI не пропали path из baseline | нет `/api/note/{id}` |
| `junit-mini/` | у каждого `@Test` рядом `@DisplayName` | метод `wrongPassword` |

Контракт как у `check_users.py`: JSON на stdout, exit 0 / 1 / 2. Имя файла — по проверке, не `script.py`.

Починить дырку и прогнать тот же скрипт до exit 0. Несколько предложений: почему здесь скрипт, а не ещё один чат.

Восемь шагов дома не требовать. Обязательны установка (шаг 1), понимание скрипта (шаг 4) и один свой кристалл.
